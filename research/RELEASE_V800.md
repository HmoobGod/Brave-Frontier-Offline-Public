# Brave Frontier Global v8.00.0-demo — Optional 2022 Archive Draft Arena

Based on verified v7.00 Build #175, SHA bb79af0d4aac9ea4c9adf798fa44297072a327a0.

The existing original 2022 unit encyclopedia contains **2,291 recovered Global unit forms**, but most are not native-playable, unlocked, animated or summonable. v8.00 adds a distinctly labeled **experimental archive draft** where users can search 2022 source catalog entries and select up to six standard unit forms whose archived base HP, ATK, DEF and REC are positive. These forms are temporary clones with synthetic HP scaling; they are never granted to actual roster. The UI explicitly distinguishes original archive source attributes from synthetic practice combat.

Draft teams can attempt the existing **21 2014 historical practice mission wave sets**, respecting actual quest unlock status. The same bounded simulator, round undo, original 2022 BB evidence when among the 30 mapped forms, and original attack hit references where available remain supported. This does not imply any archival form is legitimately summonable or native combat-ready.

All draft session objects stay in volatile JS and are discarded on exit or reload. Current real player squad, roster, native quest clears, rewards, Energy, inventory, saving, Android package identity and signing are unmodified. Incomplete source forms are excluded; source image shown only if archived. These historical wave sets remain 2014 data, not verified 2022 native formations.

Do not present the optional draft as restoration of all 2,291 units. Additional unit sprites, SBB, original mechanics, original quest encounter tables and progression remain outstanding. CI must validate all inherited regressions, draft and undo tests, then Android signed debug APK.
