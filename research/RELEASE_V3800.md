# v38.00 — Optional Original Global Dungeon Battle Backdrop

Baseline: v37.00 opt-in original full-screen event theater.

The 20 exact 2022 Global event-script dungeon JPG associations, already recovered and source-matched in v27.00, are now available as an **opt-in battle background** in the existing offline story mission HUD. This makes the live demo combat presentation closer to the recovered Global stage art for supported original dungeons without altering any quests or native battle behavior. The source is determined from the currently selected 2022 dungeon event, not inferred by element or region.

The switch is off by default and affects only the current UI session. Switching to training or an unsupported dungeon restores the original battle background. It changes no battle mechanics, source enemy formations, energy consumption, drops, rewards, localStorage, v7 saves, permissions or the Android signing key.

The source event background itself is exact, but matching it to a live battle panel is an optional visual approximation; native battle stage geometry and camera/motion are not restored.
