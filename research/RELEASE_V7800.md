# Brave Frontier Global v78.00 — Live Original-Ailment and Support Status Readout

**Baseline:** exact successful v77.00 Build #309, SHA `10c2f3770b654bfc253b3ec65c78065f9abe3581`, signed debug APK artifact verified.

Seven releases of status restoration and a 2022 original-source group Regeneration item are now operational in prototype combat. However, the core UI does not show a combined ally-by-ally overview of Poison, Weakness, Sickness, Injury, Curse, Paralysis, party status immunity, and Regeneration. v78 adds a compact, auto-updating battle-side status readout using **only the existing authoritative in-battle state APIs**: v57 ailments, v76 Nullifier, v77 Regeneration. It is accessible through a collapsible battle panel, hidden outside archive combat and when there are no effects. Each status carries a concise description of its established consequence, while the two 3-turn support effects show their remaining **simulated** rounds.

**Important source boundary:** original status IDs and remedy scope are authenticated by `F_ITEM_MST_Ver1027.json`; status effects are independently documented in Global mechanics references, and v76/v77 item metadata is archived. Actual original enemy procs, UI art/status icons, tick boundaries, resistances and status duration math have *not* been recovered. This readout creates no new ailment, changes no combat math, inflicts no status, writes no saves and alters no original unit assets. It presents battle-local consequences, including action/BB locks, with clear DEMO timing attribution.

Tests assert the six status names on a single allied unit, selective cures and action blocking indicators, simultaneous Nullifier + Regeneration protection and simulated round countdown, expiry, mode/reset separation, DOM idempotency, and unchanged `P` and `bf_global_offline_demo_v7`. Original Android package identity, signing key, no-INTERNET permission and all prior Playwright/Android regressions are preserved. The candidate is not Current until exact GitHub Actions success with uploaded APK.
