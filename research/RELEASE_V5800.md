# Brave Frontier Global v58.00 — Poison HP Tick Foundation

Based on exact successful v57.00 Build. The 2022 original item master supplies the poison remedy identity/code 1 from item #20200; v57 captures cure contracts #20200/#20210/#20220/#20230/#50200 with battle-local status registration.

An independent historic Brave Frontier Global community reference (https://bravefrontierglobal.fandom.com/wiki/Status_Counter, accessed 2026-10-23) states that **poison deals 10% of target maximum HP at end of every turn**, and player ailments last three turns. This is a community-documented behavior, **not a decoded code path from the original 2022 executable**. v58 introduces a targeted, in-memory poison tick processor that wraps the existing DEMO enemy phase and applies 10% max HP, with a conservative `max(1, floor(maxHp/10))` DEMO integer rounding choice. It processes a unit no more than once in a round, removes poison after three ticks when the unit survives, never applies it to a KO/empty/inactive unit, and refuses to process a stale battle reset.

**Limitations:** Enemy status proc rates and which original archived NPC skills inflict poison remain unverified, so **this does not make enemies inflict poison yet**. The current victory/new-wave fast path skips enemyPhase and therefore does not necessarily apply a poison tick on a wave-transition turn; do not claim the full native turn scheduler. Other five ailments still have registry/cure identities without their original combat stat or action effects. Shield/guard handling and exact fractional rounding not fully decoded; poison currently bypasses Guard.

All code is isolated in a v58 module loaded after v57, no save/inventory writes, no Android app ID, debug signer, manifest permission, original art, quest values, skill or stock changes. Test deterministic 10% tick, one tick/round, three-turn removal, no poison on KO, cure interruption, stale reset, stable v7 identity and inherited Chromium and Android package regressions. Promote only an exact successful CI artifact.
