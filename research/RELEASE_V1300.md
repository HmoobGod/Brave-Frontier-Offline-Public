The original 2022 Global lore codex contains original evolution recipes for many source unit forms. The optional v10.00 evolution explorer now displays original recipe target form IDs, recorded Zel and Karma values and distinct material IDs/names/types with multiplicities. All recipe details come directly from BFGlobalUnitArchive.originalRecord(id), the same validated 2022 codex already used by the encyclopedia; no new external payload, invented requirements or native progression mechanics.

A sourceRecipe(from,to) lookup only returns a recorded recipe, and returned material arrays are cloned to prevent accidental mutation. Missing recipes are labeled unavailable; any recipe target with no archived form is shown without speculative navigation.

This is strictly read-only reference data, not an enabled evolution or crafting system. No player currency, materials, original quest progress, owned roster, save schema v7, app ID or signing identity changes. The 2014 historical enemy practice data remains separate. Regression tests validate source recipe fidelity across all 2,291 forms, user interface, archive draft continuity and unchanged saves.
