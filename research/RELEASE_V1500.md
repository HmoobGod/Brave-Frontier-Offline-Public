# Brave Frontier Global v15.00 — Source-Verified Evolution Routes

Based on verified v14.00 Build #194, GitHub commit 1cdcb251945775e3691ac5f2f7b48b5e9c1ef486.

The existing 2022 Global evolution explorer and v14 recipe material planner now have a companion **multi-stage recorded-recipe route viewer** inside the optional research hub. Start with a temporary archive-draft form and choose a catalog-matched reachable source target. A bounded breadth-first search finds the shortest chain of actual recovered recipe steps (at most twelve hops). The view names each original intermediate form and independently totals every stage's source Zel, Karma and duplicate materials.

**No inferred source material costs:** evolution relations without recovered original recipe records do not count as traversable paths. Other 2022 Global encyclopedia forms without viable recipes are explicitly shown as having no available route. This is not in-game evolution or an inventory availability check. No real roster, player resources, game progress, v7 save schema, app signing, network permissions or battle systems are changed.

Verification must cover source-recipe fidelity along every returned hop, bounds/cycle handling, UI navigation, temporary draft interaction, no-save protection and the existing Android/Playwright regression suite.
